# BookMyStay #

### 1. Room Inventory Management ###
  - Allows to add new room types, update room counts and prices

### 2. Room Search & Availability Check ###
  - Guests can search for rooms and view available options.

### 3. Booking Request Queue (First-Come-First-Served) ###
  - Process Booking requests in order they arrived

### 4. Reservation Confirmation & Room Allocation ###
  - Once request is processed, a unique room is assigned to the guest

### 5. Add-On Service Selection ###
  - Guests can enhance their bookings by selecting additional services.

### 6. Booking History & Reporting ###
  - All confirmed registrations are stored for tracking.
